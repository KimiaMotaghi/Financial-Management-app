نام پروژه : مدیریت مالی شخصی ( جیبتو)
معرفی کوتاه ایده و هدف محصول: 
این پروژه یک اپلیکیشن مدیریت مالی موبایل (توسعه‌یافته با جاوا) است که با هدف ردیابی هزینه‌های مشترک در خانه یا سفر، بودجه‌بندی پویا و ارسال هشدارهای لحظه‌ای برای اقساط طراحی شده است.
قابلیت ها و امکانات اصلی محصول : 
*ردیابی هزینه‌های مشترک: ثبت و تقسیم آسان هزینه‌ها برای خانوارها یا سفرهای گروهی.
* بودجه‌بندی پویا: تعیین سقف بودجه با دریافت هشدارهای لحظه‌ای هنگام نزدیک شدن به حد مجاز.
* سیستم یادآور هوشمند: اعلان‌های خودکار برای پرداخت بدهی‌ها، قسط‌ها و هزینه‌های دوره‌ای.
* گزارش‌گیری: تولید گزارش‌های آماری و نمودارهای مالی
ساختار کلی مخزن و توضیح پوشه های مهم:

├── app/                  # کدهای اصلی و سورس‌کد اپلیکیشن اندروید (Java)
│   ├── src/main/java/    # کدهای منطقی جاوا (Activities, Services, Controllers)
│   └── src/main/res/     # منابع گرافیکی، لایه‌بندی‌ها (XML) و تصاویر
├── docs/                 # مستندات پروژه، اسناد فازهای تحویل و فایل‌های PDF
├── assets/               # فایل‌های کمکی، نمونه داده‌ها و دارایی‌های پروژه
└── README.md             # مستندات و معرفی پروژه
توضیح پوشه‌های مهم:

app/ (سورس‌کد اصلی):
این پوشه قلب تپنده پروژه است و تمامی فایل‌های توسعه‌یافته با زبان جاوا برای پیاده‌سازی منطق ردیابی هزینه‌ها، بودجه‌بندی پویا و سیستم یادآور در آن قرار می‌گیرد.
 بخش src/main/res/ نیز شامل فایل‌های رابط کاربری (XML) برای طراحی صفحات اپلیکیشن است.


docs/ (مستندات و فایل‌های پروژه):
محل نگهداری فایل‌های مستندسازی، گزارش‌های فازهای تحویل پروژه (مانند همین Project Proposal) و فایل‌های خروجی PDF دانشگاهی است تا اعضای تیم یا استاد به راحتی به آن‌ها دسترسی داشته باشند.
assets/ (فایل‌های جانبی):
برای نگهداری فایل‌های گرافیکی، فونت‌ها یا داده‌های اولیه‌ای که ممکن است اپلیکیشن برای تست یا راه‌اندازی نیاز داشته باشد استفاده می‌شود.
